# Smart Color Vision 🌈👁️

A real-time computer vision project built with Python and OpenCV that detects and tracks rainbow colors using HSV color segmentation.

## Features

- Real-time webcam processing
- Detects multiple colors:
  - Red
  - Orange
  - Yellow
  - Green
  - Blue
  - Indigo
  - Violet
- Draws bounding boxes around detected objects
- Displays the detected color name
- Calculates object area
- Calculates object center coordinates
- Shows the total number of detected objects
- Displays real-time FPS
- Noise reduction using morphological operations
- Optional detection mask using the `M` key
- Basic brightness enhancement

## Technologies

- Python
- OpenCV
- HSV Color Space
- Contour Detection
- Image Processing
